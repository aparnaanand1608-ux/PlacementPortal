# 🎓 Placement Portal

A Java-based Placement Management System developed using **Data Structures and Algorithms (DSA)**. The project helps manage student profiles, job opportunities, and placement eligibility through an organised system.

## 🚀 Features

- **Student Management:** Store and manage student profiles.
- **Binary Search Tree (BST):** Organise student records.
- **Job Management:** Maintain available job opportunities using HashMap.
- **Eligibility Checking:** Identify students eligible for specific jobs.
- **Priority Queue:** Rank eligible applications.
- **CGPA Sorting:** Sort students based on academic performance.
- **File Handling:** Store placement records in `placements.txt`.

## 🛠️ Technologies Used

- Java
- Data Structures and Algorithms
- Object-Oriented Programming
- File Handling

## 📚 Data Structures Implemented

| Data Structure | Application |
|---|---|
| Binary Search Tree | Student profile management |
| HashMap | Job information management |
| Priority Queue | Application ranking |
| Sorting | CGPA-based student ranking |

## ▶️ How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/aparnaanand1608-ux/PlacementPortal.git
   ```

2. Open the project in VS Code or any Java IDE.

3. Compile the Java file:

   ```bash
   javac PlacementPortal.java
   ```

4. Run the program:

   ```bash
   java PlacementPortal
   ```
